# Fotos de la app

Pon aquí las fotos de restaurantes y platos (`.jpg` o `.png`, mejor de menos de 300 KB).

Luego escribe la ruta en `lib/data/restaurants_data.dart`, por ejemplo:

```dart
image: 'assets/images/la_esquina_paisa.jpg',
```

Mientras un restaurante o plato no tenga foto, la app muestra su emoji sobre un fondo de color.
